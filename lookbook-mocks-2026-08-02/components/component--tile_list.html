Component: Tile list

The stacked-tile pattern used inside current-step cards and on the ineligible page. Four variants: info sub-tile, resource row, doc chip, and tip callout. Tiles stack with grid gap-1.5. Radii: rounded-lg/xl on mobile, rounded-[6px_2px] / rounded-[14px_4px] on the desktop state roadmap.

1 · Info sub-tile — white tile inside a current-step card (title + body, optional status chip)

Save your confirmation

Save your confirmation number or take a screenshot as proof you applied.

Respond by the deadline
Important

If your agency requests an interview or documents, respond by the deadline to avoid delays.

Border is coral-divider inside coral current-step cards; use roadmap-line on neutral surfaces. Icon color carries the meaning: coral-dark = action, green = positive, muted-dim = neutral. Desktop radius: rounded-[6px_2px].

2 · Resource row — icon tile + title + body, optional CTA (ineligible page, resource lists)

findhelp.org

Search free local programs — food pantries, rent and utility help, low-cost clinics — by ZIP code.

Find help near me
211

Call or text 211 any time. Free and confidential — a real person helps you find support nearby.

The row carrying the page's primary action gets the surface-muted background, a filled navy icon tile, and the single coral CTA; quieter rows stay white with outlined icon tiles. Desktop radius: rounded-[14px_4px], icon tile rounded-[10px_3px].

3 · Doc chip — compact document/requirement label

Photo ID Proof of income
Photo ID Proof of income Proof of where you live

Stacked full-width rows on mobile (rounded-lg, text-xs); 3-up grid with rounded-[6px_2px] and text-[9.5px] on desktop. Always followed by the reassurance line: "You can still start even if you don't have everything."

4 · Tip callout — pale-yellow advisory (PROPOSED tokens #fdf8e3 / #ecdfa8, not yet in the theme)

Tip: Save your agency's number as a contact on your phone so you don't miss messages.

The only non-token colors in the current mocks. If adopted, suggest adding as --color-roadmap-tip:#fdf8e3 and --color-roadmap-tip-line:#ecdfa8.
